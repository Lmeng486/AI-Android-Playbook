# R-0204: 超时与配额耗尽后的降级决策

## 规则
在移动端受限算力与 I/O 环境下，Agent 遇到文件检索无结果或超时时，禁止反复加深层数或改用更宽路径重试，必须遵循降级阶梯，并在超过阈值时主动熔断，交还决策权。

## 降级阶梯
1. **Level 0 (标准带参检索)**: `find "$HOME" -maxdepth 4 -xdev -name "*.ext"`
2. **Level 1 (换轻量工具)**: `rg --files "$HOME" | grep '\.ext$'`（rg 默认过滤 `.git`、`node_modules`）
3. **Level 2 (浅层结构探测)**: 停止搜索具体文件，使用 `ls -la "$HOME"` 探测顶层架构
4. **Level 3 (主动熔断交还)**: 输出探测摘要并请求用户指引

## 熔断报告规范
遇到以下条件立即熔断：
- 连续 2 次命令报错（如 `os error 13`）。
- 单次或累计耗时 > 30 秒。
- 达到 Level 2 仍无法定位。

禁止无报告静默放弃，禁止盲目提升深度（如 `-maxdepth 10`）或扫描全盘。
